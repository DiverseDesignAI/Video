# Original YUVIO V5 audio

Original oscillator/noise synthesis created for the user's YUVIO portfolio video. No third-party recordings or samples were used. These project audio files may be published with the YUVIO portfolio film.

- music.wav: original musical bed, unmastered.
- ui-effects.wav: original interaction effects, unmastered.
- public/v5/soundtrack.wav: mastered full stereo mix.
- mastering.json: integrated loudness and 4× oversampled true-peak measurements.
- tools/compose_v5_audio.py: reproducible score, effects and mastering pipeline; dependencies numpy, scipy, pyloudnorm.
