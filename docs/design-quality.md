# Визуальное качество YUVIO

## Установка

- Impeccable: официальный скил `impeccable` 4.6.0, целиком с references, скриптами и метаданными Codex. Windows-движок 0.1.15 загружен штатным launcher с проверкой контрольной суммы; запуск context и detect проверен. Автоматические hooks не установлены: detector можно запускать явно.
- Taste Skill: существующий `design-taste-frontend` обновлён до текущего v2, вместе с библиотекой направлений, референсами, ассетами и проверяющими скриптами. Предыдущая локальная копия сохранена в резерве вне каталога активных скилов. Генератор направлений и source lint проверены.
- Smoke test на стартовом HyperFrames HTML: Taste lint — 0 FAIL / 0 WARN; Impeccable detect выдал предупреждение overused-font (Arial). Это техническая заглушка, не финальный дизайн YUVIO.
- Оба SKILL.md проходят проверку структуры. Реальный браузерный inspector Taste Skill в рамках установки не запускался; это отдельная проверка конкретного результата.
- Скилы доступны в Codex со следующего сообщения. Их установка локальна; этот репозиторий хранит инструкции проекта и сведения об установке.

## Разница

Taste Skill помогает искать арт-направление через библиотеку конкретных композиций, типографики, изображений и примеров. Impeccable помогает довести выбранное решение: иерархия, ритм, цвет, UX и осмысленная анимация. Они преимущественно про интерфейсы и сайты; для видео применяются подходящие принципы композиции, типографики и движения, а экспортом управляет выбранный видеодвижок.

## Что переносим в видео

1. Идея кадра берётся из YUVIO: валюты, перевод, карта, контроль денег, собственный знак и реальные экраны.
2. У каждого кадра — главный объект и читаемая иерархия. Декоративные эффекты не заменяют содержание.
3. Сохраняем фирменные цвета, шрифты, логотип и формы из Figma. Ограничения скилов не являются основанием самовольно менять бренд.
4. Движение показывает связь: откуда пришли деньги, что изменилось, куда перешёл элемент. В проморолике допустим один сильный визуальный приём с тихой поддержкой.
5. Смотрим результат глазами: ключевые кадры, переходы, читаемость на телефоне и полный MP4. Успешная сборка и отсутствие предупреждений не доказывают качество.
6. Исходники и итоговые материалы храним по правилам Video; зависимости и временные проверки не коммитим.

## Ограничения исследования

Заявленные 247 сайтов в Taste Skill — исследование автора с оценками моделей по скриншотам, а не независимое доказательство универсального хорошего вкуса. Часть запретов — прямо обозначенный авторский стиль. Применяем их с учётом задачи и существующего бренда. Установка не обучает заново модель: она добавляет доступные инструкции, материалы и инструменты проверки.
