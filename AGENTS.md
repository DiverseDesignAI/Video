# Video project instructions

The user wants work stored in https://github.com/DiverseDesignAI/Video and wants distinctive, considered design rather than generic AI styling.

For visual work, consult applicable installed Impeccable and design-taste-frontend guidance for direction and critique. Use the selected video engine's skills for frame timing, rendering and export. Website-specific constraints and motion quotas do not automatically apply to video.

YUVIO's Figma file is the visual source: https://www.figma.com/design/xdHhVrICh4tuIjB1bTbsxh/ . Preserve its brand, typography, logo and supplied assets unless the user requests a redesign. Do not replace violet or gradients solely because a skill discourages their generic use.

Derive the visual idea from the actual product and its content. Check rendered keyframes, scene transitions, mobile readability and the exported video before claiming visual completion. Distinguish static checks, successful builds and verified final renders.

Keep source and project documentation in GitHub; exclude dependencies, caches and credentials. Rendering on GitHub Actions has not yet been set up. See docs/design-quality.md for the design workflow and installation limitations.
